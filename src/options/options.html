    Anki flashcards

    Translate Tube can turn the words you pick into flashcards in Anki, a free app that shows each card again right before you would forget it. It runs on Windows, Mac and Linux, and syncs to phone apps.

    1. Install Anki from apps.ankiweb.net and open it.
    2. Add the AnkiConnect add-on: in Anki choose Tools → Add-ons → Get Add-ons…, paste the code 2055492159 and click OK.
    3. Restart Anki: close it completely and open it again. The add-on starts only after a restart.
    4. Allow Translate Tube: Anki asks once whether to allow this extension. Click Yes.
